# Публичная версия проекта

Это портфолио исходного кода, а не выпуск для реального оборудования. Сохранены собственные реализации, тесты, сцены и конфигурации в пределах проверенного состава. Авторские права на исходники не переоформляются: новая лицензия на весь проект не назначалась. Лицензии включённых сторонних компонентов сохранены рядом с ними.

## Восстановление зависимостей

Откройте проект в версии Unity из ProjectSettings/ProjectVersion.txt. Восстановите пакеты из Packages/manifest.json и NuGet-конфигурации. Отдельно установите используемые внешние библиотеки (включая DOTween, если он используется) на законных условиях. Визуальные и звуковые ассеты отсутствуют; назначьте собственные либо лицензированные аналоги. Исходные GUID-ссылки сцен сохранены, поэтому до восстановления ресурсов возможны missing references.

## Аппаратный ключ

В этой копии используется только демонстрационный AES-256 ключ с байтами 00, 01, …, 1F. Это общедоступный тестовый набор, не секрет и не ключ рабочего контроллера. Связанные контрольные примеры пересчитаны под него. Для реальной интеграции передайте собственный ключ через приватную конфигурацию; не коммитьте его. Лицензионный launcher, если требуется приложением, также поставляется отдельно. Реальное оборудование и платёжные операции при подготовке публикации не запускались.

## Проверки и ограничения

Публикация прошла проверку состава, размера файлов и отсутствия обнаруженных рабочих ключей. Успешная сборка всех игровых проектов без исключённых ресурсов не заявляется. Полный локальный проект не изменялся.
