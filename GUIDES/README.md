# Guides

Эта папка является центральным местом для хранения проектных гайдов, связанных с зависимостями, настройкой Unity-проекта, workflow и проектными соглашениями.

Для гайдов по пакетам и внешним зависимостям в этом проекте действует одно правило:

- под каждую зависимость создается отдельная папка
- внутри папки зависимости основной материал хранится в `README.md`
- общий корень `GUIDES/` не используется для смешивания инструкций по разным пакетам в одном файле

## Подразделы

- `packages/` — внутри находятся только отдельные папки зависимостей и пакетов из roadmap
- `architecture/` — гайды по архитектурным подходам, организации кода, Dependency Injection, сценам и прикладным Unity-паттернам
- `legacy/` — аудит и разбор унаследованных материалов, которые могут быть полезны для переноса в текущий проект
