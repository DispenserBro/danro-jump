# Unity Test Framework

## Зачем это нужно

`Unity Test Framework` нужен для `Edit Mode` и `Play Mode` тестов внутри проекта.

## Что важно для текущего проекта

В текущем `Packages/manifest.json` пакет уже есть:

```text
com.unity.test-framework
```

Это значит, что в проекте его, скорее всего, не нужно устанавливать заново. Нужно проверить и довести до рабочего состояния.

## Как установить, если пакета нет

1. Открой `Window > Package Manager`.
2. Найди `Test Framework`.
3. Нажми `Install`.

Если добавляешь пакет по имени, используй:

```text
com.unity.test-framework
```

По официальной документации пакет обычно уже поставляется вместе с Unity Editor и автоматически доступен в проектах, созданных на Unity `2019.2+`.

## Как настроить после установки

1. Открой `Window > General > Test Runner`.
2. Проверь, что доступны вкладки:
   - `EditMode`
   - `PlayMode`
3. Подготовь в `Assets/` две зоны под тесты:
   - `Assets/Tests/EditMode`
   - `Assets/Tests/PlayMode`
4. Создай хотя бы по одному тесту в каждом режиме.

## Минимальная практическая настройка для проекта

Для первого этапа достаточно:

- убедиться, что `Test Runner` открывается
- создать хотя бы один `Edit Mode` test
- создать хотя бы один `Play Mode` test
- договориться, что новая критичная логика позже получает тесты в одной из этих двух зон

## Как проверить, что всё настроено

- `Test Runner` открывается
- Unity видит тесты
- хотя бы один `Edit Mode` тест запускается успешно
- хотя бы один `Play Mode` тест запускается успешно
