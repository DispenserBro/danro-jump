# Architecture Guides

Этот раздел объединяет гайды по архитектурным решениям для `Danro Jump`.

Здесь стоит хранить материалы, которые описывают не установку отдельных пакетов, а подходы к построению проекта:

- как организовывать зависимости
- как управлять сценами
- как отделять прикладную логику от Unity API
- как строить собственные абстракции и сервисные слои
- как переиспользовать полезный legacy-код из `Assets/Temp/Legacy` без прямого импорта в runtime

## Доступные гайды

- `extenject-dependency-injection/README.md` — практический гайд по `Extenject` и организации `Dependency Injection` в Unity-проекте
- `scene-management/README.md` — гайд по управлению сценами, переходам, additive loading и разделению игровых контекстов
- `unity-abstractions/README.md` — гайд по созданию собственных надстроек и абстракций над классами и API Unity
- `hardware-com-system/README.md` — гайд по архитектуре аппаратной интеграции и COM-взаимодействию (ввод-вывод, потоки, шифрование, автореконнект)
- `prize-economy-system/README.md` — гайд по архитектуре призовой экономики (кредиты, сессии, выдача призов, статистика сессий)

## Как использовать этот раздел

- Если вопрос касается отдельного пакета, материал должен лежать в `GUIDES/packages/`.
- Если вопрос касается устройства кодовой базы и архитектурных паттернов, материал должен лежать в `GUIDES/architecture/`.
- Если вопрос касается старого кода из `Assets/Temp/Legacy`, сначала сверяйся с `GUIDES/legacy/temp-legacy-audit/README.md`, а затем переносить стоит только выбранные идеи, модели и алгоритмы.
